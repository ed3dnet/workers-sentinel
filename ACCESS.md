# Authorized external systems

## Cloudflare

The agent is authorized to deploy the Sentinel application in this repository to the Tilmon Engineering Cloudflare account. Before deployment, verify the active Cloudflare identity, select and explicitly pin the Tilmon Engineering account, follow the deployment procedure in `README.md`, and verify the resulting deployment. This authorization is for this Sentinel application only; it does not authorize unrelated Cloudflare changes, credential changes, or destructive resource operations.
